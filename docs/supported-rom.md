# 対応ROMとGame Boy側の前提

## 対応している版

現在のGame Boy用payloadは、日本版『ポケットモンスター 赤』revision 1の次のROMだけを対象としている。

| 項目 | 値 |
|---|---|
| ヘッダタイトル | `POKEMON RED` |
| 容量 | 524,288バイト |
| Revision | 1 |
| SHA-256 | `751ABB1FB2B2D6B91DC631FA10ED36BD07F682CB5C3FEBE6C8F0E3DABC1FAE1C` |

会話ポインタ、ROMルーチン、WRAM上のバイナリエディタ配置に依存するため、緑、青、ピカチュウ版、海外版、revision 0へ同じアドレスを入力しない。

本プロジェクトはROM、セーブデータ、エミュレータを配布しない。利用者自身が用意したROMとセーブデータを使用する。

## ROMの確認

PowerShellでリポジトリのルートから次を実行する。

```powershell
.\tools\Test-SupportedRom.ps1 -RomPath 'C:\path\to\your\Pokemon Red.gb'
```

対応版なら`"supported": true`が表示され、終了コード0で終わる。`false`になった場合はGame Boy用コードを入力せず、吸い出したカートリッジの版を確認する。この検査はROMを読み取るだけで、書き換えない。

## バイナリエディタの導入

バイナリエディタの作成方法は、おせけん氏のYouTube動画「初代ポケモン お手軽20分。バイナリエディタ作成チャート解説」を参照する。

- [バイナリエディタ作成チャート解説](https://youtu.be/qV1EJU6howc)

動画の手順を最後まで完了し、次の状態にしてから本プロジェクトの入力へ進む。

- ゲーム内でバイナリエディタを開ける
- 任意のWRAMアドレスへ移動して値を編集できる
- カーソル位置からコードを実行できる
- エディタを終了してゲームへ戻れる

本プロジェクトで確認したエディタは、カーソル位置でSELECTを単独入力するとコードを実行する版である。導入した版の動画説明と操作が異なる場合は、実行操作だけは導入元の説明に従う。

## 写真講評payloadの入力

バイナリエディタを導入した後、[バイナリエディタ入力表](../analysis/oak-photo-link-input.md)の6ブロック、合計285バイトを入力する。

入力後はカーソルを`DA00`へ移動し、導入したエディタのコード実行操作を行う。確認済みの版ではSELECT単独で実行する。処理がエディタへ戻ったらSTARTでエディタを終了し、Bでメニューを閉じる。

インストーラはオーキド研究所の会話ポインタをWRAM上の新しい表へ向ける。撮影のたびに`DA00`を再実行する必要はないが、マップ移動やゲーム再起動などで会話ポインタが作り直された場合は再実行する。

## セーブデータについて

入力前に、利用者自身の方法でセーブデータをバックアップする。公開リポジトリの入力表はROMやSAVへ自動的にパッチを当てず、ゲーム内バイナリエディタからWRAMへ入力する値だけを掲載する。
