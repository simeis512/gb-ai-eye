# Fritzing配線図の作図仕様

このページは、GB AI Eyeの配線をFritzingで再現するための作図仕様である。写真の被覆色ではなく、Game Boy端子番号、信号名、レベルシフタのチャンネル名を基準に結線する。

## 図面に置く部品

- Game Boyリンクプラグ、6端子
- 4チャンネル双方向5 V / 3.3 Vレベルシフタ
- Seeed Studio XIAO ESP32S3 Sense
- 保護回路付き3.7 V 1セルLiPo
- SPST電源スイッチ

FritzingにGame Boyリンクプラグの部品がない場合は、汎用6ピンコネクタを使い、各ピンへ`GB1`から`GB6`を表示する。XIAO ESP32S3 Senseの部品がない場合は、汎用ヘッダで`D0`、`D1`、`D3`、`3V3`、`GND`、`BAT+`、`BAT-`を表す。カメラ拡張基板は信号配線を持たないため、外形を示すだけでよい。

## 正式なネット表

| ネット名 | Game Boy | レベルシフタ | XIAO | 方向 |
|---|---|---|---|---|
| `GB_SCK` | 5 SCK | HV4 ↔ LV4 | D0 / GPIO1 | GB → XIAO |
| `GB_SOUT` | 2 SOUT | HV1 ↔ LV1 | D1 / GPIO2 | GB → XIAO |
| `GB_SIN` | 3 SIN | HV2 ↔ LV2 | D3 / GPIO4 | XIAO → GB |
| `COMMON_GND` | 6 GND | H側GND、L側GND | GND | 共通 |
| `GB_5V_HV` | 1 VCC | HV | 接続しない | シフタ5 V側電源 |
| `XIAO_3V3_LV` | 接続しない | LV | 3V3 | シフタ3.3 V側電源 |
| `BAT_POS_SW` | 接続しない | 接続しない | BAT+ | LiPo+ → スイッチ → BAT+ |
| `BAT_NEG` | 接続しない | 接続しない | BAT- / GND | LiPo- → BAT- / GND |

Game Boy端子4と、レベルシフタのHV3/LV3は使用しない。未使用線はそれぞれ個別に絶縁する。

## 動作確認済みレベルシフタの端子順

実機で使った青色4チャンネル基板を、シルク文字が読める向きに置いた場合の上からの順序は次のとおり。

```text
H側: HV4, HV3, GND, HV, HV2, HV1
L側: LV4, LV3, GND, LV, LV2, LV1
```

結線後の並びは次になる。

```text
H側: GB5, 未接続, GB6, GB1, GB3, GB2
L側: D0,  未接続, GND, 3V3, D3,  D1
```

同じ青色基板でも端子順や内部回路が異なる製品がある。基板のシルクと製品資料を確認し、外観だけで同一品と判断しない。

## Game Boyコネクタの向き

図面には、コネクタをどちらから見た図か必ず併記する。Game Boy本体のソケットを外側から見て平らな側を上にした配置と、ケーブルのプラグ接点面は左右が逆になる。

```text
本体ソケット正面:     ケーブルのプラグ接点面:
上段  2  4  6         上段  6  4  2
下段  1  3  5         下段  5  3  1
```

配線図の推奨表示は「ケーブルのプラグ接点面」である。実際のケーブル内部の色は製品やロットで異なるため、公開図へ色と端子の固定対応を書かない。組み立て時は電源を外し、テスターの導通モードで各線と端子番号を特定する。

## Fritzing上の配置

ブレッドボードビューでは、信号の流れが左から右になるように配置する。

```text
[Game Boyリンクプラグ] → [レベルシフタ] → [XIAO ESP32S3 Sense]
                                                ↑
                                      [LiPo] → [電源スイッチ]
```

- Game Boy側を左、XIAO側を右に置く。
- レベルシフタはH側をGame Boy、L側をXIAOへ向ける。
- LiPoとスイッチはXIAOの下へ置き、通信線と電源線を交差させない。
- SCK、SOUT、SINには方向矢印と信号名を添える。
- Game Boy端子4とチャンネル3には`未使用`を表示する。
- Game Boy端子1からXIAOへ線が伸びていないことが一目で分かる配置にする。

回路図ビューも作り、写真風のブレッドボードビューだけに依存しない。回路図ビューではネット名を表示し、長い線の交差を避ける。

## 推奨する図面上の配色

線色は信号を識別するための図面上の色であり、ケーブル内部の被覆色を指定するものではない。

| 用途 | 推奨色 |
|---|---|
| SCK | 青 |
| SOUT | 緑 |
| SIN | 黄 |
| 共通GND | 黒 |
| Game Boy 5 V → HV | 赤 |
| XIAO 3V3 → LV | オレンジ |
| LiPo+ | マゼンタまたは赤 |
| LiPo- | 黒 |

## 図面に入れる注意書き

次の3点を図面内へ短く記載する。

> XIAO本体はLiPoまたはUSBから独立給電する。Game Boy端子1をXIAOの5V、VBUS、BATへ接続しない。

> Game Boy、レベルシフタ、XIAOのGNDを共通にする。

> ケーブルの線色を信用せず、電源OFFで導通を確認する。

USBで書き込みやシリアル監視を行う場合も、Game Boy端子1はレベルシフタのHVだけへ接続したままとし、USB 5 V系統へ接続しない。

## 公開ファイル

清書後は次の3形式を同じリビジョンで保存する。

- `hardware/gb-ai-eye-wiring.fzz`: 編集可能なFritzingソース
- `docs/assets/gb-ai-eye-wiring.svg`: READMEや拡大表示用
- `docs/assets/gb-ai-eye-wiring.png`: noteなどSVGを直接使いにくい媒体用

PNGは文字が読めるよう横幅2,000 px以上で書き出す。図面のタイトル、リビジョン、更新日を入れ、端子対応を変更した場合は3形式を同時に更新する。

## 清書後の照合

公開前に、図面から次の接続を1本ずつ読み上げて[公開用ハードウェアガイド](hardware.md)の信号表と照合する。

1. GB5 → HV4 → LV4 → D0
2. GB2 → HV1 → LV1 → D1
3. D3 → LV2 → HV2 → GB3
4. GB6 → H/L両GND → XIAO GND
5. GB1 → HVだけ
6. XIAO 3V3 → LVだけ
7. LiPo+ → スイッチ → BAT+
8. LiPo- → BAT- / GND

最後に、GB2とGB3、LV1とLV2、信号と電源の間に短絡がないことをテスターで確認する。
